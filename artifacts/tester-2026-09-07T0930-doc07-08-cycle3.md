## Both Mediums are the same defect, and it is worth naming before the fixes

**A statement that outran what it sat on** — for the fourth and fifth time in three cycles
(TC-3567 at v2.6.0, TC-3543 at v2.7.0, TC-3573 and the Doc 04 register citation at v2.8.0, and now
both of these). What makes this pair worth recording rather than quietly fixing is that **it
recurred in the very version whose changelog named the pattern.** I wrote "a claim of mine that
outran its source" into both v2.8.0 and v2.11.0 changelogs, and in the same edit left a pin note
announcing an advance the `Source:` block never received. The lesson evidently has to be
**mechanical, not resolution-shaped** — which is why I took the harder remedy in both documents
(advance the pins) rather than the cheaper one (soften the sentence).

**Doc 07 ISS-01 (Medium) — the pin note announced an advance the `Source:` block never received.**

still read **v1.0.1**. **A pin note is a plan; the `Source:` block is the pin** — a reader who did
the right thing and checked the pin found the old version and prose claiming otherwise. **Fix:**
advanced, together with the three other stale pins the same note named.

## Decisions made

- **Advance the pins, do not soften the sentences.** Both documents have carried a "full pin-sync
  owed" debt (Doc 07 since v2.5.0, Doc 08's SDD/BKLG half since v2.8.0), and by now I had genuinely
  read the sources. **Both debts are DISCHARGED at this version.**
- **Every advance is annotated with what was actually read, and three are labelled *scoped*.**
  Doc 07: MTP → v1.6.0 *(§0.5 S4/S5, §14 register)*; SRS → v2.17.1 *(§4.45 and §8 FR-131 Scenarios
  8 and 9, read line by line — the criteria TC-3570..TC-3575 derive from)*; SDD → v2.13.0
  *(§10.12.3 / DES-094 clause 9 — the text TC-3568 and TC-3488 verify)*. Doc 08: SDD → v2.13.0
  *(§15's FR-131 DES assignment and §10.12.3 / clause 9)*. **"Scoped" is not a hedge:** a pin
  asserts the document was written against that version, and for the sections cited it was.
  Claiming an end-to-end read of three source documents **in order to clear a Low** would be the
  same over-claim these cycles keep correcting — trading a cosmetic defect for a substantive one.
- **BKLG is labelled differently, on purpose: version-only, NOT re-read.** No section of Doc 05 was
  read this session. It advances because leaving an *In Review* pin on a document Approved four
  versions ago misstates which release these documents were written against, and because the
  `US-####` ids cited resolve in v2.5.0 (**I checked `US-0134` by grep**). **What is still owed is
  the story-by-story re-read**, and both documents say so. What is discharged is the *staleness*,
  not the *reading*.
- **One consequence named rather than left implicit.** With SDD now pinned at **v2.13.0 Approved**,
  the caveat the Doc 08 §3.1 FR-131 row and §7 entry 117 carry — that the DES assignment is "cited
  as current corrected text, **not an approved source**" — is **spent**. I annotated it as spent
  rather than deleting it, and stated flatly that **it closes nothing**: FR-131 was never open
  because its sources were provisional. **A settled source and a built control are different
  things, and only the second closes a Must row.**
- **No suite re-run, deliberately.** Nothing testable changed in either document, so **R-19
  (2026-09-07, 625/625, plus the UT-0889 block case by case) stands** and no run id is minted.
  Re-running to accompany a header-only patch would add a run id and no information. **The
  post-merge re-run owed since R-18 is still owed** — the tree is still uncommitted.
- **Patch bumps, not minors.** Every fix in both documents is in the header block. A version that
  touches no case, count, link or ruling does not earn a minor.
