## Decisions made

- **FR-064 stays OPEN, and I wrote *two* reasons into its gap note, not one.** The obvious one is
  DES-065 (a v2/Phase-3 chain nullifier, unbuilt). The one that would have been easy to lose is
  **semantics**: FR-064's text reads *auto-void-on-join*, the code does *refuse-until-leave*. The
  explicit-leave form is stricter — and stricter is still not what the requirement says. Doc 02 is
  product-owner-owned, so I named the **product-owner** in the gap-log owner column for entry 55
  alongside the architect. A design fix alone cannot close that half.
- **Did not extend FR-021.** The hand-off flagged it "only if genuinely evidenced". It is not:
  one-member-one-equal-vote is about tally weight, and this drop adds no vote-weight or tally test.
  Recording it would have been fabricated coverage in the one document whose job is to prevent that.
- **Kept the 24 cases as `Pass (inh.)` even though I had observed them.** I ran the full suite twice
  during the Doc 06 cycle-3 review and saw 542/542 green, which covers every one of these files. I
  still filed them in the **inherited** bucket, because the observation was at file granularity in a
  review run rather than case-by-case against each TC, and it keeps the TS-PARTY precedent and the
  Doc 08 buckets consistent. The stronger evidence is recorded in Doc 07 §0.2 / §9 R-12 and in a
  §2 corroboration note that explicitly says the accounting **understates** the evidence. Better to
  under-claim in the RTM and show the working.
- **No story newly meets DoD** — checked story by story, not assumed. US-0024/US-0025 gained real
  evidence but were already among the 13 done (FR-020/FR-022 were COMPLETE before this drop).
  US-0073 not done (FR-064 open); US-0131 stays Partial (FR-130 G-TRACE); US-0133/US-0134 not done.
- **TC-3539/TC-3540 recorded as guards, with their provenance.** Both were minted from defects the
