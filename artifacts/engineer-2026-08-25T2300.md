## Decisions made

**D-01 — Trailing period on ver subtitles.** The SDD backing-aware sub-table (v2.7.1) shows both ver subtitle strings with a trailing period. The existing code (v1 scaffold drop) had `'Your vote counts. Your identity is not stored'` without a period. The new VER_SUBTITLE_V1 and VER_SUBTITLE_V2 constants both include the trailing period to match the SDD verbatim. Updated tests use the period-inclusive strings.

**D-02 — UT-0751 updated, not weakened.** UT-0751 previously asserted the v2 subtitle in a default render (no backingProperties). That assertion was testing the wrong behavior (the defect). Updating it to assert the v1 subtitle in the default case is a correction, not a weakening — it tests the correct clause-7 behavior.

**D-03 — UT-0757 absence test uses v2 path.** The textContent absence test in UT-0757 now passes `unlinkable: true` to test the v2 (stronger) path. This choice preserves the test's value (checking that NO extra data leaks, regardless of which subtitle is shown) while ensuring the test is specific about which copy string it expects.

**D-04 — No .editorconfig.** No `.editorconfig` exists in the repo. §2.6 of Doc 06 documents de facto conventions as observed in existing files. This is flagged below.

**D-05 — Owner line correction.** Doc 06 v1.1.0 listed "Ravi Deshmukh — Principal Architect (acting engineer, Phase 0/1 drop)". The canonical engineer per Doc 13 §7 RACI (line 740) is "Samuel Oyelaran — Engineering Lead". Corrected in v2.0.0.
